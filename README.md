# Dell Chromebook 3110 screw map

This is the student version. Upload this whole folder to GitHub. It has no editor, so adding `?edit` to the address does nothing.

Students start on a diagram of the main parts, then pick a teardown step and hover over, tap, or tab to a screw to see its size. The strip above each photo shows every screw lined up side by side, and a bracket marks the one in use.

The screw sizes come from Dell's Chromebook 3110 Service Manual. They do not apply to the 3110 2-in-1, which has a different list.

## Put it on GitHub

1. Create a new public repository.
2. Choose **Add file > Upload files**, drag in everything from this folder, including the `images` and `fonts` folders, and commit.
3. Go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. After a minute or two the site is at `https://YOUR-NAME.github.io/REPO-NAME/`.

## Update the pins

Place pins in the **dell-3110-pin-editor** folder on your own computer. Then upload the `pin-positions.js` it downloads to this repository, replacing the old file. Students see the change within a minute or two.

## Changing the screw facts

Sizes, counts, step names, tips and the start page parts list are all in `screw-data.js`. Change it in both folders so they stay matched.
